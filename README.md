# cfgc — 分层部署配置编译工具

仅使用 Go 标准库实现的本地配置编译器：合并公共参数与环境覆盖文件，
展开 `${NAME}` 引用，生成可直接消费的 JSON 配置和可审查的来源报告。
工具不读取任何系统环境变量，所有输入均来自显式指定的文件。

## 用法

```
go run . compile -common common.conf -env prod.conf -sensitive sensitive.json
go run . explain -common common.conf -env prod.conf -sensitive sensitive.json
```

- `compile`：输出合并并展开引用后的 JSON 配置（`{"KEY": "value"}`），
  供部署程序直接消费，包含真实值（含敏感值）。
- `explain`：输出每个键的审查报告（来源文件与行号、覆盖记录、依赖列表、
  敏感标记），不含任何值，可安全地贴入评审或工单系统。

两种输出的键名均按字典序稳定排序。任何解析或引用错误都会以非零码退出，
且不会输出部分配置。

## 参数文件语法

- 每行一条 `KEY = value`，`=` 两侧空白可省略。
- 键必须以英文字母或下划线开头，只含字母、数字和下划线。
- 空行与以 `#` 开头的整行注释被忽略。
- 同一文件内重复定义同一键会报错（报文件与行号）；
  环境文件中的键覆盖公共文件中的同名键，并记录在审查报告中。

值的三种写法：

| 写法 | 语义 |
| --- | --- |
| `KEY = bare value` | 去掉两端空白；`${NAME}` 引用会被展开 |
| `KEY = 'literal'` | 单引号内容按原文保留，不识别转义，也不展开引用 |
| `KEY = "escaped"` | 支持 `\\`、`\"`、`\n` 三种转义；`${NAME}` 引用会被展开 |

其他转义序列、残缺引号、引号后的多余字符都会报错并定位到文件与行。

## 引用展开

- 未加引号与双引号值中的 `${NAME}` 会被展开，允许前向引用与间接引用。
- 引用读取的是覆盖后的最终定义（环境文件优先）。
- 引用未定义的键或出现循环依赖都会报错，且不输出任何配置。
- 单引号中的 `${NAME}` 只是普通文本，不产生依赖。

## 敏感键

`-sensitive` 指定一个 JSON 字符串数组文件，例如 `["PASSWORD", "API_KEY"]`。
敏感标记沿引用关系传递：凡（直接或间接）引用了敏感键的键也被视为敏感。
审查报告与错误信息只包含键名、来源与依赖，绝不包含敏感值。

## 测试

```
go test ./...
```

覆盖跨文件覆盖、前向/间接引用、引用循环、未定义引用、引号与转义、
同文件重复键以及间接脱敏等场景。
